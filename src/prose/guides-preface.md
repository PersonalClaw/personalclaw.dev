# Guides

The guides walk through running PersonalClaw: installing it, getting a first conversation working, and the specific setups that come up early. They are task-shaped, so each one is meant to be followed start to finish rather than skimmed.

Read them in the order the list below gives. It is core's own directory order, and installation comes first.

A guide tells you what to do; it does not enumerate every option. When you want the exact flag, config key or route rather than a walkthrough, [reference](/docs/reference) is the section that has it. When you want to know why a subsystem behaves the way a guide says it does, that is [architecture](/docs/architecture).

These pages are core's text, published from the release this site was built from. If a guide's instructions do not match the version you are running, check [release provenance](/release) for which release that is — and if they do not match the release either, the correction belongs in [core]({{coreRepoUrl}}/docs/guides), which is where these files live.
